# Протокол разработки 15.10.2026

## Завершено

- Просмотр исходников CScore и публичных API `LimitForceSolver.ForCrossSection`, `AllFactor`.
- Создан .NET 10 JSON-адаптер `src/CScorePileRunner/Program.cs` (ULS-NDM, N/Mx/My).
- Создан Python-оркестратор `pile_rebar.py` для генерации вариантов, геометрического отсева, анализа результатов и вывода CSV/JSON.
- Никаких собственных формул расчёта прочности железобетонных сечений не добавлено.
- Неуспешные/незавершённые расчёты не могут получить статус `pass_uls`.
- Созданы 11 модульных тестов Python, **11/11 пройдено локально**.
- На демонстрационной БНС Ø1000 получены 32 геометрически допустимых варианта, **нулевая информация о прочности пока не вычислена**.
- Добавлен ручной workflow сборки и запуска CScore на Windows с зафиксированным upstream SHA.

## Не выполнено / блокирует численные выводы

- Здесь отсутствует `dotnet`, а контейнер не имеет доступа к `github.com` и `dot.net` (DNS недоступен).
- C# проект не скомпилирован; API-вызовы подобраны по upstream-тестам, но не подтверждены сборкой.
- GitHub Actions workflow написан, **не запускался**. Его выполнение нельзя считать доказанным.
- Верификация относительно АРБАТ, СП 63 и контрольных примеров — не выполнена.
- Проверки crack width, shear, eta, anchorage, конструктивные требования — не реализованы и не должны быть подразумеваемы по статусу `pass_uls`.
- Изменений в пользовательских репозиториях GitHub не делалось, поскольку отдельный репозиторий для прототипа не был указан.
