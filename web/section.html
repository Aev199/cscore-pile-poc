1 Сечение и арматура

Защитный слой — до наружной поверхности хомута или навивки. Положение осей стержней показано на схеме.

Геометрия каркаса и зазоры

Поперечное армирование

b = 0,885D; h₀ = b − a. Один полный виток — две условные ветви. a задаётся для приведённого сечения, не равно автоматически защитному слою сваи.

2 Материалы

Исходный шаблон B30 / A500. Характеристики можно изменить ниже.

Модули, диаграммы и материалы SLS

3 Усилия

N < 0 — сжатие; N > 0 — растяжение. M — относительно оси x. Для СВГ M > 0 растягивает грань y−. При смене знака меняется растянутая грань.

Нормативные усилия SLS задаются отдельно от расчётных ULS. N — полное нормативное продольное усилие; Mдлит — длительная часть момента.

Расчётные условия

Локальная модель CScore с постоянными заданными N/M/Q. Расстояния задаются в обе стороны. Проверка длины анкеровки выполняется отдельно.
