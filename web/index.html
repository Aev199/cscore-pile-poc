Исходные данные проверок CScore

Длины и долю длительного момента задаёт инженер. Для η нужно также подтвердить учёт случайного эксцентриситета в исходных усилиях.

Расстояния относятся только к выбранной отметке. Для проверки наклонного момента нужны положительные расстояния в обе стороны. Пусто — данных нет; 0 — опора в локальной модели не задана. Проверка использует постоянные усилия одного сечения, без обрывов стержней и переходов шага; она остаётся предварительной. Коэффициент k не заменяет расчёт длины анкеровки.

БНС · Q со спиральной навивкой

Геометрия по ВНИИГС, 1984, примечанию к п. 3.3: b = 0,885D; h₀ = b − a. Совместное применение с СП 63 и эффективность спирали требуют обоснования инженера. Проверка локальная, с постоянным шагом; подбор навивки не выполняется.

χ задаётся по принятой расчётной модели, без коэффициента подъёма витка: его программа учитывает отдельно. Значение по умолчанию не назначено. χ = 0 — без вклада навивки в Q.
