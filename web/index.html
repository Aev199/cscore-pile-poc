Таблица усилий

Вставьте из Excel 7 столбцов: отметка · сочетание · ULS/SLS · N · M · Q · Mдлит. Разделитель — табуляция или «;». Сжатие N отрицательное.

Для SLS Mдлит обязателен; N принимается одинаковой для полной и длительной части. Для ULS последний столбец оставьте пустым. Усилия уже должны содержать необходимые коэффициенты.
