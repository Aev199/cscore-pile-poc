# Модуль «Эпюры PLAXIS» — армирование сваи или стены по всей длине

Второй режим приложения «Сечения БНС и СВГ» (переключатель в заголовке окна). Берёт расчётные
усилия выбранного элемента из PLAXIS 2D Output (или группы свай из PLAXIS 3D), для каждого сечения по длине строит РСУ,
подбирает требуемую продольную арматуру и Asw/sw и сохраняет эпюру армирования в JSON для
модуля армирования в Revit ([формат](reinforcement-profile-json.md)).

## Подготовка PLAXIS

1. Откройте рассчитанный и сохранённый проект в **PLAXIS 2D** (CONNECT V22) или **PLAXIS 3D Input**.
2. **Expert → Configure remote scripting server**: порт (например 10000) и пароль, запустите сервер.
3. Приложению нужен Python из поставки PLAXIS (в нём есть модуль `plxscripting`). Обычно это
   `C:\ProgramData\Bentley\Geotechnical\PLAXIS Python Distribution V2\python\python.exe`;
   приложение ищет его само, иначе укажите вручную кнопкой «…». Путь и порты запоминаются.

Модуль только читает модель и результаты: проект PLAXIS не меняется.

## Порядок работы

0. Карточка **«Задача»**:
   - **сценарий**:
     | Сценарий | PLAXIS | Усилия на элемент | Сечение |
     |---|---|---|---|
     | СВГ | 2D, Plate | на 1 п.м × **ширина захватки** (она же b сечения) | СВГ |
     | Сваи ограждения (БСС, БНС с шагом) | 2D, Plate или Embedded beam row | на 1 п.м × **шаг свай** | БНС |
     | Сваи из 3D | 3D, Embedded beam / Beam | на сваю; группа — единое армирование | БНС |

     Тип сечения в режиме «Сечение» переключается по сценарию; после загрузки сценарий
     предлагается по модели (3D → сваи 3D, Embedded beam row → сваи ограждения);
   - **расчёт**: «Подбор армирования» — требуемая As по длине (для Revit) или «Проверка сечения» —
     сечение из режима «Сечение» как задано (стержни, ряды, хомуты) по всей длине: Kmax каждого
     сечения и определяющая проверка.
1. В режиме **«Сечение»** задайте сечение: размеры, защитный слой, раскладку, материалы,
   коэффициенты, трещиностойкость, μ (l₀ = μ·L, L — длина элемента из PLAXIS), проверку Q с шагом
   и ветвями хомутов. Для подбора диаметры не важны (подбирается площадь), для проверки — задайте
   фактическое армирование.
2. В **PLAXIS Input** выделите сваю или стену: Plate / Embedded beam row или линию, на которой
   они заданы; можно несколько участков одной вертикали. В **PLAXIS 3D** — одну или несколько
   свай (Embedded beam или Beam): выделенные сваи образуют группу с единым армированием
   (см. «Группа свай из PLAXIS 3D»).
3. Режим **«Эпюры PLAXIS»** → карточка **«Усилия PLAXIS»**: источник — «Огибающие PLAXIS» или
   «Усилия выбранных стадий» (читаются усилия каждой не-Safety стадии, в списке «Стадии» отметьте
   нужные — например, одну; ссылки «все / ни одной»), порт Input и пароль →
   **«Загрузить выделенное в Input»**. Программа:
   - читает выделение и фазы Input, фазы расчёта **Safety** исключает;
   - сама открывает **Output** (как кнопка «Вывод» в Input) на последней рассчитанной фазе;
   - находит в Output участки выбранного элемента (после разбиения сеткой `Plate_1` → `Plate_1_1`,
     `Plate_1_2`, …);
   - читает **огибающие, построенные Output** (Envelope max/min N, M, Q), — по одной на каждую
     ветку фаз, на её последней фазе, а не результаты каждой фазы. Огибающая фазы в PLAXIS
     охватывает её и все предыдущие фазы ветки; ветки Safety отбрасываются;
   - если Safety-фаза стоит внутри ветки (её огибающая захватила бы Safety) или Output не даёт
     огибающих, читает узловые N, M, Q по каждой фазе, кроме Safety.

   В списке тогда — ветки (число охваченных стадий); под каждой — её экстремумы N, |M|, |Q|,
   чтобы сразу видеть, какая ветка определяет огибающую. Исключённые (Safety) и неактивные стадии —
   под кнопкой. Тип расчёта Safety распознаётся по `DeformCalcType` в любой форме и по способу
   нагружения «Incremental multipliers»; сырые значения пишутся в журнал.
   Путь к Python и ручное подключение к Output — в раскрывающемся блоке «Подключение».
   Output, открытый прошлой загрузкой, используется снова (если отвечает и в нём есть выбранные
   элементы): открытие Output через Input загружает всю модель — в большой 3D-модели больше минуты.
   PLAXIS 3D: каждая величина читается одним запросом на всю модель и ветку, узлы свай отбираются по
   оси в плане; основное время — загрузка каждой ветки в Output (~25 с в модели на 800+ конструкций).
   Журнал последней выгрузки — `%TEMP%\section-app-plaxis.log`.

   Если Output не отвечает (другой пароль его сервера), откройте Output вручную, включите в нём
   сервер и используйте «Из открытого Output вручную»: порт Output → «Подключиться» → отметить
   элементы → «Загрузить усилия».
4. **Фазы**: отметьте фазы, входящие в РСУ, и вид каждой: основное, кратковременное (γb1 = 1),
   сейсмическое (m_tr, СП 14), особое (СП 296). Огибающая строится по отмеченным фазам.
5. **Параметры**:
   - единицы силы и длины — берутся из Output, проверьте;
   - стена — **котлован**: справа (со стороны большего X) или слева. Программа предлагает сторону
     по перемещениям стены (стена смещается в сторону котлована). От неё зависят только названия
     граней в таблице, на графике и в JSON: «со стороны котлована» / «со стороны грунта».
     Арматура подбирается **на обе грани всегда**: каждая — по моментам, растягивающим именно её,
     из всех отмеченных фаз (для огибающих — Mmax и Mmin). Если растянутая зона на разных этапах
     переходит с одной стороны на другую, это и даёт армирование обеих граней на этой отметке;
   - стена — **знак M в PLAXIS** (служебная настройка): какую грань растягивает M > 0. Знак момента
     PLAXIS зависит от направления, в котором нарисована линия плиты; по нему положительные и
     отрицательные моменты относятся к своим граням. Программа определяет его по прогибу Ux
     (выпуклая грань растянута) и пишет долю совпавших узлов; при малой доле — проверьте по Output;
   - «Не учитывать N» — N = 0 во всех РСУ (в запас при изгибе, когда N ограждения не определено);
   - «Nmax = 0 огибающей — свая ещё не устроена» (по умолчанию включено): огибающая ветки охватывает и
     стадии до устройства сваи, где N = 0; если Nmax = 0 по всей длине при сжатии в Nmin, пара
     «N = 0 с Mmax» (изгиб без сжатия) не учитывается — иначе армирование сжатых свай завышается.
     Под галочкой — сколько таких свай (веток). Точнее всего — «Усилия выбранных стадий»: N, M, Q одновременны;
   - «Поперечная арматура (проверка Q)» — та же настройка, что в «Сечение» → Расчёт (там шаг и
     ветви); нужно подтвердить конструктивные требования, иначе Q не проверяется и Asw — «—»;
   - **срезка пиков** M и/или Q (на ответственность инженера): зоны «от — до отметки», по хорде
     (эпюра внутри заменяется прямой между значениями на границах) или до заданного значения;
     исходная огибающая показана на графике пунктиром, зоны попадают в JSON для Revit;
   - шаг сечений, μmin (стена — на каждую грань от b·h0, свая — от площади), γf для перехода
     к нормативным усилиям (трещины), kдл;
   - отметьте «Единицы, масштаб и знак M сверены с Output» — без этого расчёт не запускается.
6. **Рассчитать** → эпюры и таблица: требуемое армирование или проверка сечения (заданная As и K).
   Выберите строку таблицы — под ней сечение на этой отметке: требуемая As, разложенная стандартными
   стержнями (Ø12…40; из раскладок, которые помещаются с просветом и шагом до 400 мм и дают не более
   5 % стали сверх самой экономной, — с наименьшим числом стержней; ряды стены — как в «Сечении»).
   Это иллюстрация (то же — `suggested_bars` в JSON): окончательную раскладку выбирает модуль Revit.
   При открытии выбрано определяющее сечение (наибольшая As; в проверке — наибольший K).
7. **Сохранить для Revit…** — `*.reinforcement.json`. **Сохранить…** — проект эпюры
   (`*.profile.json`: усилия PLAXIS, фазы, параметры и сечение) — открывается без PLAXIS.

Без PLAXIS можно открыть демонстрационные выгрузки `examples/profile/svg-demo.plaxis.json`
(синтетическая стена 15 м, три фазы) и `examples/profile/pile-group-3d.plaxis.json` (группа из
четырёх свай PLAXIS 3D разной длины, одна с оголовком на 0,5 м ниже).

## Типизация свай из PLAXIS 3D

«Расчёт → Типизация свай (3D)» и «Число типов». Выделите в Input сваи (хоть все) — для каждой подбирается
своё армирование, затем сваи объединяются в заданное число типов каркасов.

1. **Таблицы требуемой арматуры.** Подбор ядром в каждом сечении каждой сваи — часы (один расчёт ядра —
   секунды). Поэтому требуемая As кольца табулируется как функция N и M (Asw/sw — функция N и Q) точным
   подбором CScore в узлах сетки 7 × 12 по диапазону усилий свай — для каждой группы свай с одинаковой
   длиной и видом сочетаний; ~100 точек, минуты. Таблицы считаются один раз: смена числа типов
   пересчитывает быстро.
2. **Каждая свая** — требуемая As и Asw/sw в сечениях по её длине (наибольшая по строкам РСУ из таблиц).
3. **Объединение.** В один тип попадают только сваи с одинаковыми отметками оголовка и низа (±50 мм);
   типов не меньше, чем таких групп. Начиная с «тип на сваю», объединяются два типа, чья общая огибающая
   добавляет меньше всего стали, — пока не останется заданное число типов (расположение в плане не
   учитывается).
4. **Зоны типа.** Одно число стержней для всех каркасов свай одной длины (по наибольшей площади, которую
   может дать кольцо, с запасом 15 %; локальные пики, где не хватает и полного кольца, его не задают),
   по зонам и типам меняется только диаметр; спираль — стандартный Ø при заданном шаге. Зоны короче 2 м
   присоединяются к более сильной соседней.
5. **Проверка ядром** (у K на каркасе — определяющая проверка: Q, N,M, трещ., уст.). Каждая зона каждого типа проверяется полным расчётом CScore с её стержнями и
   спиралью на определяющих сочетаниях свай типа (3 по требуемой As, 2 по Asw); при K > 1 зона усиливается
   и проверяется снова: Q — спиралью, остальное — диаметром. Если не помогает (Q сверх несущей способности
   ствола при любой спирали, не хватает Ø40), зона остаётся с K > 1 и пояснением: обычно это пик усилий у
   оголовка или узла — срезка пиков или «Усилия выбранных стадий» (огибающие сочетают экстремумы N и M
   разных стадий, в т. ч. растяжение) либо больший диаметр сваи.

После расчёта экран режима — для работы с типами (панель «Задача / Усилия / Параметры» скрыта, кнопка
«Параметры» вверху её возвращает):

- **Число типов и кривая «сталь ↔ число типов»** — сталь по огибающим (без округления до стержней) для
  каждого числа типов автоматической сборки; щелчок по точке задаёт число типов и собирает заново
  (таблицы не пересчитываются, проверяются ядром только новые типы). «Собрать» — то же для числа в поле.
- **План свай**: цвет — тип или требуемая As сваи (синий — мало, красный — много); наведение — свая,
  тип, As, отметки; колесо — масштаб, правая кнопка — сдвиг, двойной щелчок — вписать; щелчок — свая
  (Ctrl — добавить), рамка — несколько свай. Сваи невыбранных типов приглушены.
- **Каркасы типов** — все типы рядом в одном вертикальном масштабе: зоны (насыщенность — площадь),
  стержни, спираль, K зоны (красный — K > 1 или не определён), кг на сваю; щелчок — тип. Справа — сечение
  самой армированной зоны и перечень зон выбранного типа.
- **Ручная правка**: «Перенести выбранные» — выбранные сваи в тип из списка; «Новый тип» — выбранные
  сваи в отдельный тип (разделение); «Закрепить / открепить» — автоматическая сборка не меняет тип.
  В тип — только сваи с одинаковыми отметками оголовка и низа. После правки ядром проверяются только
  изменившиеся типы.
- **Таблица**: «Типы» (сваи, отметки, зоны, спираль, кг/св., K, закреплён) и «Сваи» (тип, отметки,
  требуемая As max, в скольких сечениях свая определяет огибающую типа, сталь сверх её собственной).
  Выбор строки синхронизирован с планом и каркасами.

Сталь сравнивается с вариантом «свой каркас на каждую сваю» по тем же правилам — это цена типизации.
«Сохранить таблицу…» — CSV (Excel): сваи с типами и координатами, зоны типов.

## 3D-вид и эпюра материалов

Кнопка **«3D-вид»** (сваи из PLAXIS 3D) открывает в браузере страницу со сценой (three.js встроен в страницу,
интернет не нужен; файл — `%TEMP%\section-app-3d-….html`, его можно сохранить и переслать):

- сваи на своих местах и отметках, после типизации — в цвете типа; вращение, сдвиг, масштаб мышью;
- на каждой свае эпюра выбранной величины — N (сжатие влево, растяжение вправо), |M|, |Q|, As требуемая;
  эпюры развёрнуты к наблюдателю, масштаб — ползунком; фильтр по типу, подписи;
- **«наложить несущую способность»** (после типизации) — эпюра материалов поверх усилий, зелёной
  ступенчатой линией по зонам каркаса типа: Mult и Qult при наименее выгодном N зоны (наименьшее сжатие
  или наибольшее растяжение свай типа в зоне), Nult сжатия и растяжения, As принятая; красные точки —
  усилие больше несущей способности;
- щелчок по свае — справа её эпюра выбранной величины с наложением, зоны типа и таблица зон
  (стержни, спираль, Mult, Qult, Nult, K).
- **наведение на эпюру** — значения на этой отметке (риска поперёк эпюры): N min…max, |M|, |Q|,
  требуемые As и Asw/sw (интервала подбора), каркас зоны (стержни, спираль, K), Mult, Qult, Nult зоны;
- сваи — осями (балка нулевой толщины), «объём свай» — цилиндрами диаметра сваи.

Несущая способность считается ядром CScore (прочность нормального сечения без η — Mult и Nult;
наклонное сечение и полоса со спиралью зоны — Qult; нужна проверка Q с подтверждением конструктивных
требований), поиском по лучу нагрузки на грубой сетке: десяток расчётов на величину и зону.

## Группа свай из PLAXIS 3D

- В Input 3D выделяются сваи — Embedded beam или Beam (или линии, на которых они заданы). Каждая
  выделенная свая — член группы; её участки в Output (`EmbeddedBeam_1_1`, `_2`, …) объединяются.
- Усилия PLAXIS 3D — на сваю (шаг свай не нужен). Момент и поперечная сила круглой сваи —
  равнодействующие: M = √(M2² + M3²), Q = √(Q12² + Q13²).
- Огибающие Output (по умолчанию): максимумы |M2| и |M3| могут быть в разных фазах, поэтому они
  складываются геометрически — в запас, не более чем в √2 раз. Точный момент в каждой фазе —
  с галочкой «Читать по фазам».
- **Единое армирование**: в каждом сечении РСУ собираются от всех свай группы, требуемая площадь —
  по худшей свае. Определяющая свая видна в сочетании («EmbeddedBeam_2, Phase_3: Mmax» или
  «огибающая EmbeddedBeam_2 (из 4 свай)…»).
- «Совместить сваи по оголовкам» (по умолчанию): эпюры свай откладываются от их оголовков, отметки
  берутся по самой высокой свае (на графике «Отм.*»). Так сваи с разными отметками голов получают
  одно армирование по длине сваи от оголовка. Без галочки — по отметкам модели.
- Длина эпюры — по самой длинной свае; ниже концов коротких свай в сечения идут только длинные.
- Сваи должны быть вертикальными (отклонение оси до 50 мм).

## Как считается

- Усилия PLAXIS считаются расчётными (частные коэффициенты в PLAXIS), γf = 1 для прочности.
  Погонные усилия умножаются на ширину сечения стены b или на шаг свай.
- Сечения идут через заданный шаг от верха. Каждое представляет интервал ± шаг/2: в РСУ
  попадают все узлы PLAXIS интервала, поэтому пики между сечениями не теряются.
- РСУ сечения — для каждого вида сочетаний из всех отмеченных фаз: Mmax, Mmin, Nmax, Nmin,
  |Q|max с сопутствующими усилиями. По огибающим совместных усилий нет, поэтому РСУ — углы
  огибающей интервала: Mmax и Mmin, каждый с Nmin и с Nmax, Q = |Q|max (в запас).
- Требуемая площадь — наименьшая, при которой выполнены все проверки ядра CScore: прочность по
  деформационной модели с η и случайным эксцентриситетом, продольный изгиб, ширина раскрытия
  трещин (или их отсутствие). Она не зависит от числа и диаметра стержней, заданных в «Сечении»:
  оси рядов фиксируются по защитному слою, ориентировочному диаметру из «Сечения», числу рядов
  (1–3) и зазору между ними, а площадь распределяется по расчётной сетке стержней (шаг ≈ 100 мм
  по ширине стены). Стена — две грани независимо (строки РСУ относятся к грани по знаку момента),
  свая — кольцо целиком.
  Поиск идёт на укрупнённой сетке сечения, найденная площадь проверяется на обычной сетке.
  Нижняя граница — μmin, верхняя — наибольший диаметр (40 мм), при котором стержни помещаются;
  у сваи — столько стержней Ø40, сколько помещается по кольцу (не число стержней из «Сечения»).
  Asw/sw считается и там, где продольной арматуры не хватило (с наибольшей площадью).
- Стена из Plate — полоса плоской задачи: изгиб только в плоскости стены (без ea и η из плоскости).
- Asw/sw — при принятом шаге и числе ветвей (свая — две ветви витка); 0 — по расчёту не требуется.

## Ограничения первой версии

- PLAXIS 2D CONNECT V22 — Plate и Embedded beam row; PLAXIS 3D — сваи Embedded beam и Beam
  (стены 3D пока нет). Только вертикальные элементы.
- Имена результатов PLAXIS 3D (N, M2, M3, Q12, Q13 и их огибающих) взяты по документации и
  проверены на имитации API; при первом запуске на 3D сверьте эпюры с Output.
- Прямое подключение не испытано на живом PLAXIS: проверены сценарий на имитации API и
  выгрузка в файле. При первом запуске сверьте эпюры с Output.
- Анкеровка, стыки, обрывы и конструктивные требования не проверяются; зонирование и раскладку
  выполняет Revit-модуль по эпюре.
